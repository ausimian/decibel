# Decibel

Decibel is an Elixir implementation of the Noise Protocol Framework.

## Development

- Use Elixir 1.19.5 with Erlang/OTP 28.3.
- Run `mix precommit` before committing. It is the authoritative local quality gate.
- Keep `@version` in `mix.exs` as the single source of truth for the project version.
- Add user-visible release notes to `RELEASE.md` using Keep a Changelog sections.
- Create releases with `mix publisho <level>`.
